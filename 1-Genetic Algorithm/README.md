# Genetic Algorithm Implementation

A Python-based implementation of a Genetic Algorithm (GA) designed to solve optimization problems and reach a target sequence or value. This project demonstrates the power of evolutionary computation through selection, crossover, and mutation processes.

## 🚀 Overview
The `Genetic.ipynb` notebook contains a complete workflow for:
- Initializing a diverse population.
- Evaluating fitness based on a specific target.
- Performing selection (Natural Selection).
- Applying Crossover (reproduction) and Mutation to maintain genetic diversity.
- Visualizing the convergence process.

## 📊 Performance
The algorithm has been tested and shows clear convergence:
- **Initial Best Score:** ~65.33%
- **Final Target Accuracy:** 100.0%

## 🛠️ Features
- **Dynamic Parameters:** Easily adjust population size, mutation rate, and target criteria.
- **Visualization:** Integrated plots to track the improvement of the best score over generations.
- **Modular Design:** Clean code structure allowing for easy modification of the fitness function.
